⚠️ Restart Disabled for Safety
The in-app restart functionality has been disabled because it is not reliably bringing the application back up on Windows.
To safely restart HomePulse:
  1. Click "Stop HomePulse" below to shut down the application gracefully.
  2. Wait for the button action to complete.
  3. Start HomePulse using one of these methods:
    • Via Task Scheduler: Open Task Scheduler, find "HomePulse", right-click and select "Run"
    • Via PowerShell: cd C:\RouterMonitorV2 then python router_monitor.py
    • Via Command Prompt: cd C:\RouterMonitorV2 && python router_monitor.py
    • Via start_monitor.bat: Double-click C:\RouterMonitorV2\start_monitor.bat
Security Note: HomePulse has no built-in login. Keep Lab access limited to trusted local networks.
